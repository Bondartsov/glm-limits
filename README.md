# GLM Limits

Расширение для Chrome, которое показывает остаток квот **GLM Coding Plan** — 5-часовую сессию и недельное окно — одним взглядом.

## Возможности

- **Метрика «Сессия (5ч)»** — токенное окно из `TOKENS_LIMIT` (unit 3, number 5)
- **Метрика «Неделя»** — из `TOKENS_LIMIT` (unit 6, number 1)
- **Автоопределение платформы** — по виду API-ключа
- **Уведомления** — одноразовые при 80%, 90% и 100% сессии
- **Мини-график расхода** — sparkline истории по каждому окну
- **Процент на иконке** — badge с уровнем расхода (сессия или неделя), цвет по порогам 50/75/90%
- **Следление за версиями** — уведомления «доступна новая версия» и «успешно обновлено»; версия и дата обновления в попапе и трее
- **Опциональная строка MCP** — из `TIME_LIMIT` (месячный счётчик)
- **Цветовая индикация** — зелёный <50%, жёлтый <75%, янтарный <90%, красный ≥90%
- **Обратный отсчёт до сброса** — обновление каждую секунду
- **Три режима отображения** — popup, отдельное окно, компактный
- **Безопасное хранение ключа** — по умолчанию только в памяти (на диск не пишется); опционально шифрование в расширении и DPAPI в трее
- **Абсолютные значения** — «1 086 / 28 000» рядом с процентом
- **Backoff** — при ошибках API опрос автоматически отдаляется (до 30 минут)

- **Активность по часам** — 24 столбца (шкала 00:00–23:00): в какие часы шла работа

- **Редизайн** — спокойная нейтральная палитра, сессия одной крупной карточкой, неделя и MCP — компактными строками
- **График активности** — скользящее окно 6 часов вокруг «сейчас» (3 назад, 3 вперёд); отметки «сейчас» и «сброс» вынесены на отдельную полку над столбцами, чтобы не сливаться, с расшифровкой под графиком
- **Недельный график** — расход по дням недели, Пн–Вс
- **Режим чисел** — «Остаток» или «Израсходовано» (попап и бейдж одновременно)
- **Пустое состояние** — вместо «Ошибка» просьба ввести ключ
- **Подтверждение сохранения** — всплывающая плашка «Сохранено»
- **Document PiP** — закрепление поверх других окон
- **Два языка** — English / Русский
- **Две темы** — Светлая / Тёмная

## API

Расширение опрашивает endpoint квот GLM:

```
GET https://open.bigmodel.cn/api/monitor/usage/quota/limit   (Китай)
GET https://api.z.ai/api/monitor/usage/quota/limit           (Международный)
```

**Аутентификация:** raw API-ключ в заголовке `Authorization` — **без префикса `Bearer`**.

Формат ответа:

```json
{
  "code": 200,
  "success": true,
  "data": {
    "level": "pro",
    "limits": [
      { "type": "TOKENS_LIMIT", "unit": 3, "number": 5, "percentage": 62, "nextResetTime": 1725000000000 },
      { "type": "TOKENS_LIMIT", "unit": 6, "number": 1, "percentage": 41, "nextResetTime": 1725700000000 },
      { "type": "TIME_LIMIT",   "unit": 3, "number": 1, "percentage": 10, "nextResetTime": 1727700000000 }
    ]
  }
}
```

- `percentage` — сколько окна **уже израсходовано**; в UI показывается остаток (100 − percentage).
- `nextResetTime` — epoch-миллисекунды; сброс по сингапурскому времени (GMT+8).
- Выбор окна: `TOKENS_LIMIT` или `CREDIT_LIMIT` (кредитные окна bigmodel.cn — `usage` = лимит, `currentValue` = потрачено, семантика `percentage` та же) с `unit=3, number=5` → сессия (5ч); `unit=6, number=1` → неделя; `TIME_LIMIT` → опциональная месячная строка MCP. Прочие часовые/недельные записи используются как fallback, если каноничных нет.

Лимиты привязаны к аккаунту и тарифу, а не к конкретному ключу: все API-ключи одного аккаунта показывают один и тот же пул квот.

## Две платформы

У GLM две независимые площадки с разными ключами и endpoint'ами:

- **Международная** — `api.z.ai` (консоль z.ai)
- **Китайская** — `open.bigmodel.cn` (консоль Zhipu / bigmodel)

В настройках выберите ту, где создан ваш API-ключ: ключи не взаимозаменяемы, endpoint подставляется автоматически. По умолчанию стоит **Авто** — площадка угадывается по виду ключа: ключ формата `id.secret` (с точкой) → bigmodel.cn, ключ с префиксом `zai` или строка без точки → z.ai. Если угадано неверно, выберите площадку вручную.

## Установка (режим разработчика)

Расширение не публикуется в Chrome Web Store, поэтому ставится как распакованное:

1. Скачайте или склонируйте репозиторий в отдельную папку.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** (переключатель в правом верхнем углу).
4. Нажмите **Загрузить распакованное расширение** и выберите папку проекта.
5. Кликните по иконке расширения на панели, нажмите ⚙ (Settings), введите API-ключ, выберите платформу (или оставьте «Авто») и нажмите **Save**.

Другие браузеры на Chromium:

- **Microsoft Edge**: откройте `edge://extensions`, включите «Режим разработчика» (переключатель слева), нажмите «Загрузить распакованное».
- **Яндекс Браузер**: `browser://tune/` → раздел «Инструменты» → «Расширения», внизу страницы включите «Режим разработчика», нажмите «Загрузить распакованное расширение».
- После изменения кода нажимайте ↻ (Reload) на карточке расширения, чтобы изменения вступили в силу.

## Обновление

- **Из трея (мышкой)**: правый клик по иконке GLM Limits в трее → **«Обновить расширение»**. Скрипт делает `git pull`, а расширение само замечает новую версию на диске и перезапускается — в течение пары минут или сразу после клика по его иконке.
- **Скриптом**: `update.bat` — `git pull` + открытие `chrome://extensions` (нажать ↻ Reload).
- **Вручную**: `git pull` в папке проекта → ↻ (Reload) в `chrome://extensions`.

Автообновление «само, без действий» для unpacked-расширений Chrome не поддерживает — только через публикацию в Web Store.

## Иконка в трее (опционально, Windows)

Системный трей Windows недоступен для браузерных расширений, поэтому трей-индикатор сделан отдельным мини-приложением на Python в папке `tray/`. Оно опрашивает тот же endpoint квот и показывает:

- цветную иконку с процентом **остатка** сессии (пороги 50/75/90% — как в расширении);
- tooltip с деталями и временем до сброса;
- **окно с подробной информацией** — левый клик по иконке: метрики с прогресс-барами, время сброса, тариф, хост, кнопка «Обновить данные»;
- меню по правой кнопке: данные, «Показать детали», «Обновить данные», **«Обновить расширение»** (git pull — расширение само перезапустится), тумблер **«Автозапуск при входе в Windows»**, «Выход»;
- уведомления при 80/90% сессии.

Запуск:

```
pip install -r tray/requirements.txt
python tray/tray_glm_limits.pyw             # трей-иконка, окно консоли не открывается
python tray/tray_glm_limits.pyw --selftest  # проверка без запуска трея
```

При первом запуске рядом со скриптом создаётся `tray_config.json` — впишите `apiKey` (тот же, что в расширении) и при желании `platform` (`auto`/`cn`/`intl`), `intervalSec` и `lang`. Ключ можно передать и через переменную окружения `GLM_API_KEY`. Конфиг перечитывается на каждом опросе — правки подхватываются сами. `tray_config.json` (с ключом) и `tray_app.log` в git не попадают.

Автозапуск включается прямо в меню трея — пункт **«Автозапуск при входе в Windows»** (прописывает/убирает ключ в ветке Run реестра текущего пользователя). Вручную, если хочется: ярлык на `pythonw.exe "C:\путь\к\проекту\tray\tray_glm_limits.pyw"` в папке `shell:startup`.

## Где взять API-ключ

- Международная платформа: консоль [z.ai](https://z.ai) → API Keys.
- Китайская платформа: консоль [bigmodel.cn](https://open.bigmodel.cn) → API Keys.

Ключ хранится только локально в браузере (`chrome.storage.local`) и отправляется исключительно на выбранный endpoint квот.

## Настройки

| Параметр         | Описание                                               |
| ---------------- | ------------------------------------------------------ |
| API Key          | API-ключ GLM Coding Plan (хранится локально)           |
| Platform         | Авто (по виду ключа), Китай или Международный          |
| Refresh interval | Интервал опроса в секундах (30–3600, по умолчанию 120) |
| View mode        | Popup, Window или Compact                              |
| Language         | English / Русский                                      |
| Theme            | Светлая / Тёмная                                       |
| Show MCP         | Показывать строку MCP                                  |
| Notifications    | Одноразовые уведомления при 80% и 90% сессии           |
| Icon badge       | Процент расхода на иконке расширения (вкл/выкл)        |
| Icon shows       | Что показывает иконка: сессия (5ч) или неделя          |
| Badge mode       | Показывать остаток (по умолчанию) или израсходовано    |

- `popup.css` — стили
- `popup.js` — рендеринг, настройки, i18n, PiP

- `update.bat` — обновление кода из репозитория одним запуском

- `tests/` — автотесты: `node --test` (JS) и `python -m unittest discover -s tests` (Python)
