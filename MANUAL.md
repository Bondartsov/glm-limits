# GLM Limits — руководство пользователя

Короткая шпаргалка: что это, как установить и как всем пользоваться. Технические детали — в [README.md](README.md).

---

## 1. Что это такое

Два инструмента, показывающих остаток лимитов твоего **GLM Coding Plan**:

| Инструмент            | Где живёт               | Для чего                                                                         |
| --------------------- | ----------------------- | -------------------------------------------------------------------------------- |
| **Расширение Chrome** | В браузере              | Проценты, графики, бейдж на иконке, уведомления                                  |
| **Иконка в трее**     | В Windows (возле часов) | Тот же процент без открытия браузера, окно деталей, обновление расширения мышкой |

Оба показывают одно и то же — они просто опрашивают один и тот же API квот.

**Про лимиты.** У Coding Plan два окна: **Сессия (5ч)** — токены, сбрасываются через 5 часов, и **Неделя** — сбрасывается раз в 7 дней (сброс по сингапурскому времени GMT+8, в интерфейсе время показано твоё локальное). Лимит привязан к аккаунту: все твои ключи показывают один и тот же пул.

## 2. Установка расширения (уже сделано на этой машине — для нового ПК)

1. Убедись, что на компьютере есть папка проекта: **`D:\Scripts_Python\glm-limits`**.
2. Открой в Chrome: `chrome://extensions`.
3. Включи **Режим разработчика** (переключатель справа вверху).
4. Нажми **Загрузить распакованное** → выбери папку `D:\Scripts_Python\glm-limits`.
5. Закрепи иконку: пазл 🧩 возле адресной строки → булавка напротив GLM Limits.
6. Кликни по иконке → шестерёнка ⚙ → введи **API-ключ** → **Save**.

**Где взять ключ:** консоль [z.ai](https://z.ai) → API Keys (международная площадка) или [open.bigmodel.cn](https://open.bigmodel.cn) (Китай). Платформа в настройках — «Авто», она определится сама по виду ключа.

**Проверка установки:** в попапе зелёная точка «Онлайн», цифры остатка; на карточке расширения в `chrome://extensions` — версия (в футере попапа тоже).

## 3. Расширение: что показывает и как настроить

### Главный экран

- **Большая цифра** — сколько процентов **осталось**.
- Полоска — то же самое наглядно: зелёная (>50%), жёлтая (>25% остатка), янтарная, красная (<10%).
- **«израсходовано X%»** — сколько сгорело.
- Строка под полосой — отсчёт до сброса и точное время («3ч 52м · Сегодня 16:56»).
- **MCP** — месячный лимит, включается галочкой в настройках.
- Внизу — версия сборки и дата последнего обновления кода, хост и время данных.

### Кнопки в шапке попапа

| Кнопка             | Действие                                    |
| ------------------ | ------------------------------------------- |
| ↻                  | Обновить данные сейчас                      |
| ⤡ (стрелки внутрь) | Компактный вид — только два процента        |
| 📌-иконка          | Закрепить окно поверх других (Document PiP) |
| ⤢                  | Открыть в отдельном окне браузера           |
| ⚙                 | Настройки                                   |

### Бейдж на иконке расширения

Цветной кружок с процентом виден всегда, даже с закрытым попапом. В настройках выбирается: показывать вообще (вкл/выкл), какую метрику (сессия или неделя) и что именно (остаток — по умолчанию, или израсходовано).

### Настройки (⚙)

Панель настроек открывается под метриками и **прокручивается колесом мыши** — тумблеры уведомлений и бейджа находятся в самом низу панели.

| Параметр         | По умолчанию | Что делает                                                  |
| ---------------- | ------------ | ----------------------------------------------------------- |
| API Key          | —            | Ключ GLM Coding Plan, хранится только у тебя                |
| Platform         | Авто         | Авто/Китай/Международный; ключи площадок не взаимозаменяемы |
| Refresh interval | 120 сек      | Как часто опрашивать API (30–3600)                          |
| View mode        | Popup        | Popup / Window / Compact                                    |
| Language         | English      | English / Русский                                           |
| Theme            | Светлая      | Светлая / Тёмная                                            |
| Show MCP         | выкл         | Показывать месячную строку MCP                              |
| Notifications    | вкл          | Уведомления при 80% и 90% сессии (по одному разу)           |
| Icon badge       | вкл          | Процент на иконке расширения                                |
| Icon shows       | Сессия (5ч)  | Какая метрика на бейдже                                     |
| Badge mode       | Остаток      | Бейдж показывает остаток или израсходовано                  |

## 4. Иконка в трее

### Запуск на новом ПК (рекомендуется)

1. Запусти `tray\tray_install.bat` двойным кликом — он сам проверит Python, установит зависимости и создаст `tray\tray_config.json`, открыв его в Блокноте.
2. Впиши `apiKey` (тот же, что в расширении), сохрани (Ctrl+S), запусти `tray_install.bat` снова — в трее появится цветная иконка с процентом.
3. Правый клик по иконке → включи **«Автозапуск при входе в Windows»**.

Если иконка не появилась — запусти `tray\tray_debug.bat`: он покажет ошибку прямо в консоли (чаще всего не установлен Python: ставится с [python.org](https://www.python.org/downloads/), при установке отметь «Add python.exe to PATH»).

Ручной путь (по-старинке): `pip install -r tray/requirements.txt` (нужен Python 3.10+) → вписать `apiKey` в `tray\tray_config.json` → двойной клик по `tray_glm_limits.pyw`.

### Как пользоваться

- **Наведи мышь** — подсказка: остаток, время сброса, неделя, тариф.
- **Левый клик** — окно с подробностями: карточки сессии и недели с полосками, время сброса, тариф, хост, строка MCP, кнопка «Обновить данные». Окно поверх всех, обновляется ежесекундно.
- **Правый клик** — меню:
  - первая строка — версия и дата последнего обновления кода;
  - строки с данными (сессия, неделя, сброс) — просто информация;
  - **«Показать детали»** — то же окно, что по левому клику;
  - **«Обновить данные»** — внеочередной опрос API;
  - **«Обновить расширение»** — подтягивает свежий код с GitHub; расширение само перезапустится в течение пары минут (или сразу после клика по его иконке); если обновились файлы самого трея — он **перезапустится автоматически**;
  - **«API-ключ…»** — ввод ключа для трея в окошке, ввод скрыт звёздочками (хранится отдельно от ключа расширения — в `tray\tray_config.json`);
  - **«Автозапуск при входе в Windows»** — галочка-тумблер: включи один раз, иконка будет появляться сама после перезагрузки;
  - **«Перезапустить»** — перезапуск трей-приложения одним кликом;
  - **«Выход»** — убрать иконку (данные в браузере продолжат работать).

Если иконки не видно возле часов — она под стрелкой **^** (можно перетащить на панель прямо на часах).

### Уведомления

При пересечении **80%** и **90%** расхода сессии приходит системное уведомление — по одному разу на каждое окно сброса, без спама.

## 5. Обновление

**Обычный способ (мышкой):** правый клик по иконке в трее → **«Обновить расширение»** → дождись уведомления «Расширение обновлено» → готово (расширение перезапустится само; можно ускорить, кликнув по его иконке в браузере).

Расширение само следит за версиями на GitHub: если вышла новая — придёт уведомление **«Доступна новая версия X»**, а после обновления — **«Расширение успешно обновлено»**. Версию и дату последнего обновления видно в футере попапа и в меню/окне трея.

**Запасной способ:** двойной клик по `update.bat` в папке проекта → нажать ↻ (Reload) на карточке расширения в открывшемся `chrome://extensions`.

Версию всегда видно в футере попапа и в заголовке окна деталей.

## 6. Если что-то не работает

| Симптом                                                          | Что делать                                                                                                                               |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Красная точка / «Ошибка» в попапе                                | Проверь ключ и платформу в настройках; если ключ из другого аккаунта — он не подойдёт                                                    |
| Бейдж серый или «—»                                              | Нет данных: ключ не задан или API недоступен                                                                                             |
| Иконки расширения нет на панели                                  | Пазл 🧩 → булавка                                                                                                                        |
| «Отключить расширения в режиме разработчика?» при запуске Chrome | Это стандартный вопрос для unpacked — жми «Отмена/оставить»                                                                              |
| Расширение вдруг само перезапустилось                            | Оно обновилось после «Обновить расширение» в трее — так и задумано                                                                       |
| Иконка трея не появляется                                        | Смотри лог `tray\tray_app.log`; чаще всего не вписан ключ в `tray_config.json`                                                           |
| Хочу перенести на другой ПК                                      | `git clone https://github.com/Bondartsov/glm-limits.git` → установи расширение заново → впиши ключ (ключи между машинами не переносятся) |

Логи расширения: `chrome://extensions` → карточка GLM Limits → «service worker» → консоль.
